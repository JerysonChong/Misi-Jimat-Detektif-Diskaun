# Misi Jimat: Detektif Diskaun
Aplikasi pembelajaran diskaun Matematik Tahun 5 menggunakan Python + Streamlit dengan tema kartun ceria terinspirasi Shinchan. Ilustrasi SVG ialah rekaan asli, bukan imej rasmi.

## MacBook
1. Buka Terminal dan masuk ke folder projek: `cd ~/Downloads/misi_jimat_shinchan` (ubah lokasi jika perlu).
2. Pasang pakej: `python3 -m pip install -r requirements.txt`
3. Jalankan: `python3 -m streamlit run app.py`
4. Buka URL tempatan yang dipaparkan, biasanya http://localhost:8501.

## Telefon
Aplikasi ini berjalan melalui pelayar web. Untuk akses telefon di luar rangkaian komputer, terbitkan projek dalam GitHub lalu deploy pada Streamlit Community Cloud. Dapatkan URL untuk dimasukkan dalam laporan.
